# Лабораторная работа 6: Функции

## Автор
Горбунова Настя (Вариант 5)

## Задача
Дан произвольный массив D размера k. Найти сумму элементов массива D, а также суммы квадратов и кубов элементов массива D.

## Входные данные
Размер массива (от 1 до 100) и сами элементы (вещественные числа).

## Выходные данные
Три строки с результатами: сумма, сумма квадратов, сумма кубов.
